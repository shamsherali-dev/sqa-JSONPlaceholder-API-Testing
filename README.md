# ReqRes REST API Functional & Integration Testing Suite

## 🚀 Overview
This repository houses a professional API Quality Assurance and Functional Testing suite targeting the ReqRes REST API platform (`https://reqres.in/`). It showcases backend validation techniques, automated assertions, payload schema verification, and HTTP status code handling across standard CRUD operations.

## 🛠️ Tech Stack & Methodologies
- **Target Platform:** ReqRes REST API (`/api/users`, `/api/login`, etc.)
- **Testing Tool:** Postman Desktop / Web Execution Environment
- **Validation Techniques:** HTTP Status Code Verification (`200`, `201`, `400`, `404`), Automated JavaScript Test Assertions, Payload Schema Validation, Negative & Boundary Testing
- **Artifacts:** API Test Plan, Exportable Postman Collection (`.json`), Defect Tracking Log, Execution Summary

## 📂 Key Project Artifacts
- `TEST_PLAN.md`: Outlines API scope, tested endpoints, HTTP methods, and performance/latency criteria.
- `API_TEST_CASES.xlsx`: Comprehensive spreadsheet test matrix mapping requests, headers, parameters, and expected JSON responses.
- `ReqRes_API_Collection.json`: Importable Postman collection pre-configured with automated test scripts and assertions.
- `DEFECT_LOG.md`: Documented API discrepancies regarding media-type validation and response payload behaviors.
- `TEST_REPORT.md`: Summary of test execution coverage, latency benchmarks, and endpoint stability metrics.
