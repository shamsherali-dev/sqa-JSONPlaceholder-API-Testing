# JSONPlaceholder REST API Functional & Integration Testing Suite

## 🚀 Overview
This repository contains a professional API Quality Assurance and Functional Testing suite targeting the JSONPlaceholder REST API platform (`https://jsonplaceholder.typicode.com/`). It showcases backend validation techniques, automated assertions, payload schema verification, and HTTP status code handling across standard CRUD operations.

## 🛠️ Tech Stack & Methodologies
- **Target Platform:** JSONPlaceholder REST API (`/posts`, `/comments`, etc.)
- **Testing Tool:** Postman Desktop / Web Execution Environment
- **Validation Techniques:** HTTP Status Code Verification (`200`, `201`, `404`), Automated JavaScript Test Assertions, Payload Schema Validation, Negative & Boundary Testing
